Build a web application called "DeepBrief" for the Replit Software Engineering Internship Challenge ("Build an App that Shows Its Work"). 

### 1. High-Level Objective
DeepBrief is a productivity app that takes technical research, benchmark verification, and executive briefing off an engineer's plate. 
The core highlight is an interactive, live "How It Works" Directed Acyclic Graph (DAG) state machine diagram that visually records each step as it runs in real time, displays millisecond latencies, and demonstrates self-healing fault recovery (retries, circuit breakers, and zero-loss crash resumption).

### 2. Tech Stack & Architecture
- Backend: Python 3.10+ with FastAPI and Uvicorn.
- Persistence: SQLite database in Write-Ahead Logging (WAL) mode for high concurrency.
- Real-Time Communication: Server-Sent Events (SSE) streaming state transitions (`/api/runs/{run_id}/events`) so the diagram updates with zero polling.
- Frontend: Modern Vanilla HTML5, CSS3, and JavaScript (ESM). No heavy frameworks required.
- Design Aesthetic: Premium dark-mode developer UI inspired by Linear and Replit (slate/midnight palette, glowing violet/indigo accents, smooth transitions, glassmorphic cards).

### 3. Pipeline Stages & Execution State Machine
The backend orchestrator must execute 6 discrete stages with intermediate checkpoints:
1. `Input Normalizer & Intent Expansion`: Validates inputs, infers technical domain, and generates orthogonal search vectors.
2. `Multi-Source Harvester`: Simulates parallel crawling across RFC repositories, benchmark labs, and post-mortems.
3. `DOM Sanitizer & Content Distiller`: Strips boilerplate, extracts numeric metrics, and normalizes semantic density.
4. `Cross-Source Fact Corroborator`: Aligns claims across sources, generates consensus scores, and flags single-source caveats.
5. `Intelligence Synthesizer`: Synthesizes an executive summary, core architectural takeaways, and a 30-day action plan.
6. `Artifact Builder & Cryptographic Signer`: Compiles a downloadable Markdown report, Slack team card, and calculates a SHA-256 verification hash.

### 4. Interactive Live "How It Works" Diagram (Frontend)
- Build a responsive SVG + HTML node graph showing all 6 stages connected by dynamic conduit lines.
- Stage Node States:
  - `PENDING`: Dashed border, dimmed.
  - `RUNNING`: Pulsing ring with glowing blue/cyan active conduit animation.
  - `RETRYING`: Amber glow showing attempt count and backoff wait time (e.g., "Retry 2/3 (in 1.2s)").
  - `FALLBACK USED`: Cyan badge showing circuit-breaker recovery.
  - `COMPLETED`: Emerald check with exact duration (e.g., "412ms").
  - `FAILED`: Crimson alert.
- Real-Time Step Inspector (Side Panel): Clicking any stage node displays:
  - Status, latency, attempt count, and fault-handling summary.
  - Tabs to switch between: "Output Checkpoint" (JSON tree), "Input Context", and "Resilience Policy".

### 5. Fault Tolerance & Resilience (Critical Engineering Requirement)
Implement a Chaos Testing Suite bar on the UI so reviewers can test failure modes live:
1. Bounded Exponential Backoff with Jitter:
   - When "Inject 429 Rate-Limit" is enabled, Stage 2 encounters a transient error, logs an amber backoff warning, waits with jitter, and automatically recovers on retry.
2. Circuit-Breaker Fallback Routing:
   - When "Inject 503 Outage" is enabled, Stage 2's primary provider fails. The orchestrator catches the outage, trips a circuit breaker, executes a fallback handler using cached archives, marks the node with `FALLBACK USED`, and continues the pipeline seamlessly.
3. Zero-Loss SQLite Checkpointing & Resumption:
   - Every completed step idempotently saves its output snapshot into SQLite.
   - When "Crash at Stage 4" is enabled, the pipeline halts abruptly.
   - The UI reveals a pulsing "Resume from Checkpoint" button.
   - Clicking resume calls `/api/runs/{run_id}/resume`, skips stages 1–3 in 0ms using saved SQLite checkpoints, and completes the remaining stages without losing prior work.

### 6. Final Deliverable View (Executive Dossier)
When a run completes, render an Executive Dossier containing:
- Executive summary callout.
- Architectural findings grid with metric cards.
- Immediate Action Plan table (Days 1–7, 30-Day, Quarterly) with priority badges.
- SHA-256 verification badge.
- "Copy Team Card" and "Download Markdown (.md)" export buttons.
- Bottom split view showing the live SSE terminal stream and a list of saved runs from SQLite.

### 7. Automated Tests & Configuration
- Include a `tests/test_resilience.py` suite verifying clean runs, backoff retries, circuit breaking, and crash resumption.
- Configure `.replit` to launch `python main.py` on port `8080`.
